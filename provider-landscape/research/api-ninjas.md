# API Ninjas (Earnings Call Transcript API)

## 1. Snapshot
- **Owner/parent:** **API Ninjas** — an independent, self-serve **API marketplace/aggregator** (not a financial-data specialist): it sells 100+ general-purpose developer APIs (facts, jokes, quotes, weather, IP lookup, image/PDF utilities, plus a finance category) through a single unified account and API key, of which the **Earnings Call Transcript API** and a companion **Earnings API** / **Earnings Calendar API** are a small niche offering, not the core business. No public evidence of VC funding, acquisition, or a named parent company — appears to be a small independent/bootstrapped operation.
- **Coverage:** Markets itself as covering **"full transcripts for all major company earnings every quarter."** No independently-verified company count or global/US split was found (unlike LSEG's ~10,400 or FactSet's ~10,000 disclosed figures) — treat coverage breadth as **unverified/self-reported** and materially narrower than the two enterprise incumbents.
- **Free tier:** **Yes, but restricted.** A free API key is available for testing/low-volume use, reportedly capped around **100 calls/hour** on the general free plan; however **commercial use of the Earnings Call Transcript (and Earnings) API is explicitly NOT permitted on the free tier** — free access is for evaluation only.
- **Pricing model & ranges:** **Public, self-serve, tiered SaaS pricing** (the sharpest contrast with StreetEvents/CallStreet's quote-only model) — published tiers named **Free, Developer, Business, Professional, Enterprise**; exact dollar amounts were not captured from search snippets (pricing page itself was egress-blocked) but the model is transparent, low-cost, credit-card self-signup, typical of "$10s–$100s/month" developer API pricing bands rather than enterprise five/six-figure licensing.

## 2. Coverage
- **Breadth:** Self-described as covering major companies' quarterly earnings calls; no disclosed total company count. Positioned by third-party comparison articles (qveris.ai, earningscall.biz) as one of several lightweight "transcript-focused" developer APIs alongside EarningsCall.biz, sitting apart from calendar-quality specialists like Intrinio/FMP/EODHD.
- **US vs global:** Not explicitly stated in available sources; general-purpose developer APIs of this type typically skew toward US-listed / SEC-reporting companies given transcript-sourcing practicality — should be assumed **US-centric** absent confirmation otherwise.
- **History depth:** Tiered by subscription level — the **Developer tier includes only the most recent 5 years**, while the **complete archive back to 2005** is reserved for **Business and Professional** subscribers. This is a distinctive and unusual design: history depth is explicitly pricing-gated, unlike the two incumbents where the archive is a fixed feature of one enterprise entitlement.
- **Audio / slides / Q&A structure:** No audio or slide-deck product found (text/transcript only). Structurally, the API **does** segment Q&A: higher tiers return a `transcript_split` array breaking the call into per-speaker turns with an `is_qa` flag distinguishing prepared remarks from Q&A — comparable in spirit to FactSet's prepared-remarks/Q&A split, delivered as a lightweight JSON field rather than a formatted document.
- **Completeness caveat:** Because this is a general API-marketplace product rather than a dedicated financial-data vendor, breadth/freshness/company-list completeness carries materially more uncertainty than the two institutional incumbents — no SLA or coverage guarantee was found.

## 3. Datasets
- **Earnings Call Transcript API** — the core dataset: full call transcript text, keyed by company ticker/quarter/year.
- **Value-add fields, tier-gated:** on **Business and Professional** plans the same endpoint additionally returns an AI-generated **`summary`**, extracted **`guidance`** and **`risk_factors`** fields, an **`overall_sentiment`** score (**-1 to +1**), and the **`transcript_split`** per-speaker/per-turn breakdown with per-turn sentiment and an `is_qa` flag — i.e., AI summarization and sentiment scoring are real, confirmed value-add-synthesis features, but explicitly withheld from the Free/Developer tiers.
- **Companion Earnings API** — likely EPS/revenue actuals-vs-estimates data (surfaced alongside the transcript API in API Ninjas' finance category); **Earnings Calendar API** — upcoming earnings dates, used by comparison articles as a complementary product for scheduling around transcript pulls.
- **Structured JSON only** — no bulk file/FTP delivery model; this is a per-request REST product, architecturally the opposite of LSEG's XML/FTP bulk feed and closer to (but simpler than) FactSet's modern REST API.

## 4. APIs & technical integration
- **Delivery:** Pure **REST/JSON**, single endpoint, simple query parameters (ticker + year/quarter) — deliberately minimal surface area. Third-party comparison (earningscall.biz) notes API Ninjas "prioritizes simplicity with a single endpoint, minimal parameters, and consistent JSON response," trading off advanced features (no official SDK) for ease of first integration.
- **Auth:** Standard API-key header auth (`X-Api-Key`), self-service signup, key issued instantly — no enterprise procurement, contract, or sales call required, the single biggest structural contrast with StreetEvents/CallStreet.
- **No official SDKs** confirmed in sources (unlike FactSet's `fds.sdk.*` packages) — plain HTTP/JSON only, though this also means zero dependency lock-in for a caller.
- **Rate limits:** ~100 requests/hour cited for the general free plan (applies across API Ninjas' whole catalog, not transcript-specific); paid tiers presumably raise or remove this, though exact paid-tier limits were not confirmed from available sources.
- **No MCP/webhook/streaming support** found — this is a synchronous request/response API, not built for real-time push delivery.

## 5. Enabling technology
- Positioned as a thin, aggregator-style API layer rather than a first-party data-collection operation — API Ninjas' broader catalog (100+ unrelated consumer/utility APIs) suggests a generic API-hosting/monetization platform pattern rather than an earnings-specific data-collection pipeline; the underlying transcript sourcing/ASR method is **not disclosed** in any source found (contrast with LSEG/FactSet, which both describe editorial correction and speaker-confidence-scored ASR pipelines).
- **AI/NLP layer:** sentiment scoring (-1 to +1) and summary/guidance/risk-factor extraction on paid tiers imply an LLM-based post-processing pass on top of the raw transcript text, but no methodology, model, or accuracy benchmark is published — treat as a black-box feature versus the incumbents' more documented (if still partly opaque) AI-summary products.
- No evidence of a desktop terminal, Workspace-equivalent UI, or enterprise data-governance tooling — this is API-only infrastructure aimed at individual developers/small teams building their own front end.

## 6. Customer / user feedback
- **No G2/Capterra/Trustpilot listing found** specifically for API Ninjas or its earnings-transcript endpoint — as a low-cost/free developer tool it sits below the review-site coverage threshold that catches enterprise vendors.
- **Third-party comparison articles** (independent developer-blog sources, not API Ninjas' own marketing) give a mixed but broadly consistent picture: **Pros** — wide API selection, simple pay-as-you-go pricing "cost-effective for smaller projects," fast/frictionless self-serve onboarding. **Cons** — "basic documentation" and "lacks extensive developer support" versus competitors, catalog "lacks curation" (quality varies API-to-API since it's a broad marketplace, not a specialist), and pay-as-you-go billing "can lead to unpredictable expenses" at scale.
- A direct 2026 comparison piece (earningscall.biz) positions a rival, purpose-built product (EarningsCall.biz, with official Python/JS SDKs and speaker-name mapping) as "the strongest choice for developers" specifically **because** API Ninjas' single-endpoint simplicity comes at the cost of fewer advanced features — i.e., informed developer opinion frames API Ninjas as a quick/cheap starting point rather than a production-grade specialist choice.
- **Segments (inferred):** indie developers, students/researchers, fintech prototypes and small startups needing a cheap or free way to pull transcript text programmatically without enterprise procurement — not a fit for institutional research desks.

## 7. Edge & positioning
- **Leads on:** **Accessibility and price** — the only one of the three profiled here with a public price list, instant self-serve signup, and a genuine (if commercially-restricted) free tier; simplest possible integration (one REST endpoint, JSON in, JSON out, no contract). Confirmed AI sentiment/summary/guidance-extraction fields on paid tiers are a real synthesis capability at a fraction of enterprise cost.
- **Lags on:** **Verified coverage, depth, and trust** — no disclosed company count, uncertain global reach (likely US-centric), history gated behind higher tiers (full 2005+ archive requires Business/Professional), no confirmed editorial/verbatim-accuracy process, no SLA, thin independent documentation/support, and zero review-site presence to triangulate reliability against. As a general API marketplace (100+ unrelated APIs) rather than an earnings-data specialist, it also carries more platform/business-continuity risk than an LSEG- or FactSet-backed product.
- **Best-for:** Individual developers, students, and early-stage fintech/AI prototypes that need cheap, fast, no-procurement access to earnings-call text (optionally with basic sentiment/summary fields) for experimentation or a narrow feature — not appropriate as the sole transcript source for institutional research where verified completeness, history, and audio/verbatim accuracy matter (that's the StreetEvents/CallStreet use case).
