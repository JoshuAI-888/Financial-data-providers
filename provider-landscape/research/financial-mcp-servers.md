# Financial-data MCP servers

## 1. Snapshot
- **Owner/parent:** The Model Context Protocol itself is an open specification created and open-sourced by Anthropic (November 2024); governance now sits with a community-run `modelcontextprotocol` org (spec, SDKs, official registry) with contributions from Anthropic, GitHub, Microsoft and others. Individual financial-data MCP *servers* are built and owned separately — either by the data vendor itself (Financial Modeling Prep, Polygon.io, CoinGecko, S&P Global, LSEG, Moody's) or by independent open-source authors wrapping a vendor's public API.
- **Coverage:** A large long-tail ecosystem (200+ MCP servers overall per the official registry, growing) including a finance/crypto category with servers for market data (Polygon, Alpha Vantage, Financial Modeling Prep, Yahoo Finance, Databento), regulatory filings (SEC EDGAR — multiple independent implementations), macro data (FRED), and crypto (CoinGecko, on-chain data). Enterprise vendors (S&P Global, LSEG, Moody's) have also begun shipping first-party MCP servers, distributed via their own docs and/or the Databricks MCP Marketplace rather than the open MCP registry.
- **Free tier:** Nearly all servers are free, open-source (MIT/Apache-licensed) code you self-host; "free" for the server itself, but most require a free-or-paid API key from the underlying data vendor (e.g., FMP, Alpha Vantage, Polygon, FRED all offer free-tier keys with rate limits; some SEC EDGAR/FRED wrappers need no key at all).
- **Pricing model & ranges:** No cost to install/run most community servers (npm/uvx/pip install, self-hosted, stdio process). Cost is entirely a function of the underlying data API's plan (e.g., FMP free tier vs. paid; Polygon.io free vs. paid tiers; CoinGecko free vs. Pro). A few vendor-hosted/remote MCP servers (S&P Global, LSEG on Databricks) are wrapped in the vendor's own commercial licensing rather than a standalone published price.

## 2. Coverage
- **Equities/market data:** Financial Modeling Prep MCP (multiple independent implementations: `imbenrabi/Financial-Modeling-Prep-MCP-Server` exposing 250+ tools across 24 categories; `cdtait/fmp-mcp-server`; `damianboh/fmp_mcp_server`); Polygon.io official MCP server (`polygon-io/mcp_polygon`, 35+ tools: trades, quotes, aggregates, options, forex, crypto, fundamentals); Alpha Vantage (community servers, e.g. via `kablewy/financial-analysis-mcp-server`); Yahoo Finance (`Alex2Yang97/yahoo-finance-mcp` — quotes, historicals, financials, options, news); Databento (low-latency market data, listed in finance/crypto MCP directories).
- **Regulatory filings:** SEC EDGAR — several independent servers: `stefanoamorelli/sec-edgar-mcp` (filings, XBRL, insider trading), `cyanheads/secedgar-mcp-server` (STDIO & Streamable HTTP), `leopoldodonnell/edgar-mcp`, `flothjl/edgar-sec-mcp` — no single "official" SEC server; fragmented community ecosystem.
- **Macro data:** FRED (Federal Reserve Economic Data) — community wrapper(s) exposing ~800,000 series / dozens of tools (GDP, inflation, employment, rates, housing).
- **Crypto:** CoinGecko official MCP server (per CoinGecko's own docs) plus community alternatives (`crazyrabbitLTC/mcp-coingecko-server` with OpenAI function-calling compatibility, `cyanheads/coingecko-mcp-server`, `BlindVibeDev/CoinGeckoMCP`).
- **Enterprise/vendor-hosted:** S&P Global Market Intelligence MCP Server, LSEG MCP server, Moody's MCP servers — first-party, published mainly via Databricks Marketplace/Agent Bricks rather than the open MCP registry; positioned for enterprise agentic workflows, not a hobbyist `npx install`.
- **New entrants (2026):** Wisesheets launched a combined Financial Data API + MCP server (SEC-sourced fundamentals) in July 2026, illustrating continued new-entrant activity in the space.

## 3. Datasets
- Domains reachable via these servers: real-time/historical equity quotes and aggregates (Polygon, FMP, Yahoo Finance), fundamentals/financial statements/ratios (FMP, Wisesheets, EDGAR/XBRL servers), analyst estimates and technical indicators (FMP, Alpha Vantage), options/forex/crypto (Polygon, CoinGecko), SEC filings and insider-trading data (EDGAR servers), macro/economic time series (FRED), and enterprise-grade real-time pricing/curves/credit data (LSEG, S&P Global, Moody's — enterprise tier only).
- Coverage is generally US-centric and equity/crypto-heavy; non-US market coverage depends entirely on the underlying vendor API (e.g., FMP free tier is US-listed only — same constraint as this repo's own FMP integration).

## 4. APIs & technical integration
- **Transport:** MCP defines three transport modes — stdio (server as a local child process; default, no network exposure, used by most self-hosted finance servers), SSE (Server-Sent Events, for remote servers over HTTP, being phased out), and Streamable HTTP (current spec, v2025-03-26+, preferred for new remote deployments).
- **Client support:** Claude Desktop and Claude Code support MCP natively (stdio and remote); ChatGPT added MCP support via "Developer Mode" (individual paid plans) and org-wide "vetted MCP apps" for Business/Enterprise, plus native remote-MCP support in the Responses API and Agents SDK (OpenAI adopted MCP roughly March 2025, per community/industry reporting); other adopters include Claude.ai Connectors, VS Code, Cursor.
- **Setup pattern:** typical install is `npx <package>` or `uvx --from git+<repo> <entrypoint>`, or `claude mcp add <name> -e API_KEY=... -- <command>` for Claude Code; server then registers a fixed tool-set (e.g., "get_stock_quote", "get_income_statement") the LLM can call. Auth is almost universally a single vendor API key passed as an environment variable to the local process — no OAuth needed for most community finance servers, though a few (SEC EDGAR/Polygon/FRED combined servers) reportedly add OAuth 2.1 for hosted/remote deployments.
- **Discovery:** the official MCP Registry (`registry.modelcontextprotocol.io`, preview launched Sept 2025) is an open, namespaced catalog (`io.github.user/server` format) intended as the canonical "app store" for servers; in practice most finance-specific servers today are found via third-party directories (PulseMCP, Glama, mcpservers.org, the `TensorBlock/awesome-mcp-servers` finance–crypto list) rather than the official registry, reflecting the ecosystem's still-fragmented discovery layer.

## 5. Enabling technology
- **Protocol:** MCP is a JSON-RPC-based client-server protocol standardizing how an LLM host (Claude, ChatGPT, etc.) discovers and calls external "tools," reads "resources," and uses "prompts" exposed by a server — described as "USB-C for AI" / a universal connector so one server implementation works across multiple LLM clients.
- **Governance model:** the spec and reference SDKs live in the `modelcontextprotocol` GitHub org; the official registry provides namespace verification tied to GitHub/domain ownership to reduce impersonation risk, but does not vet server code quality or data accuracy — anyone can publish.
- **Security posture (material caveat for this survey):** the original spec shipped without mandatory authentication, and a single malicious/compromised server can act as a bridge into every system it's connected to; documented 2026 risk classes include prompt injection via tool descriptions/data ("tool poisoning," OWASP LLM Top 10 #1 risk), credential/API-key exposure from local server processes, and lack of built-in sandboxing for third-party servers — relevant given most finance MCP servers here are unaudited community code holding a live API key in-process.

## 6. Customer / user feedback
- Ecosystem momentum: industry reporting describes MCP as now "the de facto standard" for connecting AI agents to external tools, with both Anthropic and OpenAI-side ecosystems (Claude, ChatGPT, Cursor) converging on it through 2025–2026, and comparison write-ups (Shibui Finance, MarketXLS, InsiderFinance Wire, "Synteza" practitioner's map) actively ranking finance-specific servers by breadth/reliability as of 2026 — a sign of real practitioner interest, not just vendor marketing.
- Repeated theme across 2026 comparison articles: Alpha Vantage praised as the "most versatile all-rounder" for breadth (equities, forex, crypto, technicals); Financial Modeling Prep praised for breadth of tools (250+ across 24 categories in the largest community implementation) but, like the underlying API, free-tier rate-limited; Polygon.io singled out for low-latency/tick-level use cases; FRED server praised for macro breadth (800k+ series).
- Security-community feedback is a consistent counter-signal: multiple independent 2026 security write-ups (Checkmarx, Palo Alto Unit 42, Practical DevSecOps, Veeam) flag MCP-specific attack surface (prompt injection via tool metadata, credential exfiltration, unvetted third-party servers) as an active, unresolved concern for any production deployment — directly relevant to self-hosting a community-maintained finance MCP server that holds an API key.
- No SEC-EDGAR or FRED server in this space has emerged as a single canonical/official implementation — multiple competing community forks exist for the same source, which several comparison articles note as a discoverability/trust gap versus vendor-official servers (Polygon, CoinGecko).

## 7. Edge & positioning
- **Leads on:** near-zero cost of entry (open-source, self-hosted, works with a free-tier vendor API key); works identically across Claude and ChatGPT/other MCP-speaking clients once written once ("write once, connect anywhere"); fastest-growing distribution channel for *agentic* (tool-calling, conversational) access to financial data, as opposed to bulk data transfer.
- **Lags on:** no centralized quality/accuracy vetting — community servers vary widely in maintenance and correctness; security posture is immature (prompt injection, key handling, no mandatory auth in the base spec); fragmented discovery (multiple competing servers for the same data source, e.g. SEC EDGAR); enterprise-grade real-time/institutional data (LSEG, S&P Global, Moody's) is mostly gated behind existing commercial contracts and delivered via Databricks rather than the open registry.
- **Best-for:** rapid prototyping and analyst-copilot workflows inside Claude/ChatGPT that need conversational, tool-call access to public-market data (quotes, fundamentals, filings, macro, crypto) at low/no cost; not yet a substitute for governed, audited, production data-pipeline access — for that, the Databricks Marketplace / Delta Sharing channel (see companion fact-sheet) or a direct vendor API/data-license remains the safer choice, especially given unresolved MCP security concerns.
